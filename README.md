# Redo Feature Analysis

This directory contains the source code and feature analysis results for the D-LAPA (depth-injection) paper. The main script is `redo_feature_analysis.py`, which evaluates and compares the quality of the predictive models (from Model 1 to Model 7.1) using the tensor data from the Libero10 dataset.

## Key Features

The `redo_feature_analysis.py` script performs the following tasks:
1. **Data Split**: Streams the `.pt` files from `libero10_features` and performs a video-disjoint 80/20 train/test split.
2. **Ridge Probes**: Trains Ridge Regression models to predict the action translation magnitude from RGB, Depth-only, and RGB+Depth features. The features are standardized (z-scored) using the training set statistics.
3. **Depth-Feature Alignment**: Evaluates the similarity (MSE and Cosine) between the predicted depth features from the models and the actual depth features (Ground Truth/Teacher).
4. **Index Diagnostics**: Calculates token accuracy, sequence accuracy, and the confidence level of the indices generated by the models.
5. **UMAP Visualization**: Generates UMAP spatial clustering plots and calculates Moran's I to evaluate the smoothness and representation capability of each feature type.

## Usage

Run the analysis script using the following command:

```bash
python3 redo_feature_analysis.py
```

### Configuration Arguments
- `--umap-samples`: Number of samples used for the UMAP plot (default: `5000`).
- `--seed`: Random seed for data splitting (default: `42`).
- `--ridge-alpha`: Alpha regularization coefficient for the Ridge model (default: `1000.0`).
- `--skip-umap`: Skip UMAP computation and plotting to save time.
- `--skip-plots`: Skip plotting entirely (only saves numerical results to CSV/JSON).
- `--diagnostics-only`: Skip Ridge probe training, only calculate diagnostics from previously saved CSV results.
- `--include-depth-only`: Include Depth-only baselines in the Ridge probe.

## Outputs

After running, the script will generate the following result files in the `output/feature_analysis/` directory:

- **Summary Reports**:
  - `feature_analysis_redone.md`: Detailed Markdown report containing interpretations, findings, and tabular data.
  - `feature_analysis_results.json`: A JSON file storing all numerical analysis results.

- **CSV Data**:
  - `ridge_probe_results.csv`: R2 and Spearman rho results for the Ridge models.
  - `depth_alignment_results.csv`: MSE and Mean Cosine results compared to GT Depth.
  - `depth_index_results.csv`: Token/sequence accuracy results for index prediction models.
  - `umap_moran_results.csv`: Moran's I results for UMAP.

- **Plots**:
  - `ridge_r2_probe_bars.png`: Bar chart comparing the R2 of the feature sets (RGB vs RGB + Model).
